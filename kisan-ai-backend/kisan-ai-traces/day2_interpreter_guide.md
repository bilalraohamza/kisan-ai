# Walkthrough - Python Interpreter & Venv Setup

## Mission
Guidance for activating the virtual environment and resolving IDE interpreter warnings.

## Steps Provided
- Terminal activation command for PowerShell: `.\venv\Scripts\Activate.ps1`.
- VS Code "Select Interpreter" workflow (`Ctrl+Shift+P`).
- Manual path configuration to `venv/Scripts/python.exe`.

## Verification
Confirmed that `venv\Scripts\python.exe` exists in the `kisan-ai-backend` directory.

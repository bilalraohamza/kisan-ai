# kisan-ai-traces — Antigravity Mission Logs

This folder lives at the **repo root** (`kisan-ai/kisan-ai-traces/`) and stores
every Artifact, trace, and log generated by Antigravity across both workstreams.
One file per mission. These are mandatory for hackathon submission.

> **Standing Rule (effective Day 2)**  
> All Artifacts, traces, and logs produced by Antigravity — whether for the  
> backend (Person A) or the Flutter mobile app (Person B) — **must** be saved  
> here, not inside `kisan-ai-backend/` or `kisan-ai-mobile/`.

---

## Naming Convention

```
personA_dayN_descriptive_name.md   ← backend / FastAPI work
personB_dayN_descriptive_name.md   ← Flutter mobile work
```

| File | Person | Day | What it captures |
|------|--------|-----|-----------------|
| `personA_day2_fastapi_setup.md` | A | 2 | FastAPI project scaffold & router registration |
| `day2_folder_rename.md` | — | 2 | kisan-ai-traces folder relocation note |
| `day2_interpreter_guide.md` | — | 2 | Interpreter / tooling guide |
| `THE_BRAIN.md` | — | — | Rolling index of every file in this folder |

> **Future traces** will follow the `personA_dayN_` / `personB_dayN_` prefix strictly.

---

## Rules

1. **Save here only** — never inside `kisan-ai-backend/` or `kisan-ai-mobile/`.
2. **Use the naming convention** — `personA_dayN_descriptive_name.md` or `personB_dayN_descriptive_name.md`.
3. Export/save the trace immediately after each mission completes.
4. If a mission failed and you corrected it, add a `_fix1` suffix.
5. `THE_BRAIN.md` must be updated on Day 5 to summarise every file in this folder.
